# Outbreak Investigation Simulator

Practice field epidemiology on fictional outbreaks.

**Live demo:** https://macaly-fo2l3lkahf9yo6rzgejhuj59-prod.macaly-app.com

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- 30 fictional outbreak scenarios
- Case definitions, epidemic curves and case-control odds ratios
- Choosing and justifying control measures

## Tech stack
TanStack Start, React, Tailwind CSS, Convex. Built on Macaly Cloud.
